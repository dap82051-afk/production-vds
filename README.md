# Production VDS Automatizate

Интерактивный Bash-скрипт для быстрой и безопасной настройки VDS с нуля.

## Зачем это нужно

Настройка нового сервера часто занимает много времени: нужно обновить систему, поставить базовые утилиты, настроить фаервол, установить нужные базовые сервисы (Docker, Python, Nginx). 

Данный скрипт автоматизирует всю рутину. Вы запускаете одну команду, отвечаете на пару вопросов — и получаете готовый к работе, защищенный сервер.

## Features

- 🛡️ **Security First:** Автоматическая настройка UFW (закрывает всёе порты, кроме 22(ssh), 80(HTTP), 443(HTTPS) портов).
- 🖥️ **Interactive:** Скрипт сопционально спрашивает, что именно вам нужно (Python, Docker, Nginx, PostgreSQL) и не ставит лишнего.
- 🐳 **Docker Ready:** Установка Docker из официального репозитория (с обходом типичных ошибок `dpkg`).
- 🐍 **Python Ready:** Установка `python3`, `pip` и `venv` для запуска ботов, FAST-API и др.
- 🌐 **Nginx:** Установка веб-сервера для nginx.
- ⚙️ **Base Utilities:** Установка `htop`, `git`, `tmux`, `curl`, `wget` исразу из коробки.
